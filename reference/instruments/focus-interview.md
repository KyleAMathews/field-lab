# Focus interview (`focus-interview`)

- **Phenomenon sought:** Misregistration between the stated request or supplied artifact and the user's actual aim, stakes, prior, felt uncertainty, or desired change.
- **Why use it:** The initial prompt shows what the user chose to state, not which part is live, tacit, doubtful, or consequential. Responsive questions make that hidden context available before analysis hardens around the first frame.
- **Operating range:** Use before substantive work on interpretive, strategic, personal, creative, evaluative, dialectical, or aim-dependent practical questions. This includes fact-shaped requests whose answer may vary by intended outcome, named method, specimen state, or constraints. Skip stable facts, narrow mechanical tasks, fully specified bounded outputs, and cases where prior conversation already supplies current answers. A request is not fully specified merely because it asks for one response.
- **Input:** The user's request and any supplied specimen, read in full first.
- **Perturbation:** Questions direct attention and may alter how the user understands the problem.
- **Procedure:** Reflect a provisional frame in a few sentences. Ask the single question whose answer could most change the analysis: why now, intended use or audience, current prior, strongest doubt, relevant stakes, missing experience, or what outcome would change the next move. Stop and wait. On the next exchange, reflect the answer for correction and ask another question only when a result-changing gap remains. For a practical system with several uses, first ask, “What is your main goal for it?” Do not offer forms, bundle distinct goals, or hide several decisions inside one question. If an answer could change the recommendation, do not attach a provisional number, range, diagnosis, or action. Follow the user's answer rather than completing a checklist.
- **Readout:** The user's answers, a user-confirmed or corrected specimen, and still-unanswered focus questions. Do not add a proposed explanation or next move.
- **Control:** Mark the reflected frame as provisional. Use an open correction such as “What am I misreading?” as the one question for that exchange rather than adding it to another. Let the user reject the interview.
- **Common artifact:** Leading questions manufacture the tension; a long questionnaire front-loads the orchestrator's taxonomy; rapport questions add ceremony without information; a “provisional” recommendation anchors the user before the question is answered.
- **Escalate when:** The confirmed specimen needs systematic coverage or context-isolated committed positions.
- **Stop when:** Another answer is unlikely to change the next probe or direct response.
- **What it requires:** Usually one to three exchanges in the current conversation, with one question in each.
- **Execution placement:** **Orchestrator.** It sees the live conversation and supplied material because responsive user correction is what makes the questions useful. A subagent may draft candidate questions but cannot conduct the interview. If the user cannot reply, stop or give a context-limited direct answer. The orchestrator returns the testimony and corrected frame without extending them into analysis.
