# Field Lab

The field lab is the skill's default shell. It makes ordinary chat, selective probes, systematic collection, and a full dialectic parts of one inquiry rather than separate products.

## Principles

1. **Every inquiry starts as a Walk.** Give a direct answer when that is enough.
2. **Instruments belong on the Walk.** Pull any fitting instrument without adding a file or phase tax.
3. **Default to camera mode.** On open questions, help the user observe and orient through a focus interview, intermediate readouts, anomalies, and questions.
4. **Use OODA as a brake.** The user owns the transition from Observe/Orient to Decide/Act. Do not conclude, synthesize, rank, make a substantive recommendation, plan, or act until they explicitly ask. Instrument and apparatus choices remain part of orientation.
5. **Separate observation from intervention.** State what a probe changed, hid, stressed, or introduced.
6. **Demand an access differential.** Before calling a tool an instrument, name what would remain unseen, entangled, unmeasured, or untested without it.
7. **Add controls as stakes rise.** Costly conclusions should survive another frame, model, control, or source check.
8. **Treat theories as instruments.** Hegel, Boyd, Adorno, Foucault, Derrida, Schumacher, and Rao have operating ranges and artifacts. None defines all specimens.
9. **Keep crookedness visible.** Residue, incompatible ends, and unresolved terms are valid readings.
10. **Scale to uncertainty and consequence.** Topic prestige does not set the apparatus size.
11. **Prefer cheap contact with reality.** A reversible trial may beat another conceptual pass.
12. **Materialize lazily.** An artifact must repay its cost through memory, coordination, comparison, or audit.

## Two independent axes

Walk, Survey, and Expedition set apparatus scale and persistence. Camera and engine set feedback tempo. OODA marks the authority boundary: the agent supports Observe/Orient; the user opens Decide/Act. A light Walk can fail by batching analysis faster than the user can correct it; a large Expedition can remain camera-like through interviews, checkpoints, and error-sensitive recursion.

Read [camera-loop.md](camera-loop.md) for the default cadence and hard transition gate. Do not remove interviewing merely because the inquiry remains a Walk, and do not treat a completed reading or phase as permission to conclude.

## States

### Walk

Opportunistic observation in ordinary conversation. The Walk may use no instrument or many. On nontrivial questions, it normally begins with a short focus interview, then alternates bounded exposures with user correction. Raw readouts remain in the session. Images, searches, recordings, or agent replies may arise naturally, but the Walk creates no organized workspace around them.

### Survey

Systematic collection. A Survey has at least one of these:

- an explicit collection plan or coverage goal;
- repeated or comparative readings;
- coordination across several instruments, agent runs, research tracks, or sessions;
- a need for a searchable or auditable record.

It begins by distilling the session into one Survey log. The log is a current map, not a rewritten history.

### Expedition

The full Electric Monk apparatus for a stubborn, costly, or high-stakes contradiction. It inherits all prior material, then applies strict phase gates, context-isolated committed positions, structural analysis, candidate construction, validation, and recursion.

## Quiet router

Do not expose this as a mode menu. Read the specimen and focus with the user before choosing a large route. After each answer or provisional readout, register the user's correction, then choose among four live exits:

| Exit            | Use when                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------- |
| **Pause**       | The user has enough material for now, even if no conclusion has formed                    |
| **Probe**       | One bounded uncertainty maps to a named instrument                                        |
| **Reframe**     | The inquiry has revealed a different specimen; confirm the change with the user           |
| **Promote**     | The next useful move needs systematic memory, coordination, or full procedural safeguards |

Conclusion, decision, and action are separate engine exits. Offer them only after the user explicitly asks to cross from orientation. Do not infer that transition from agreement, correction, completed research, instrument completion, or a passed phase gate.

For a non-obvious probe, state:

- the signal that prompted it;
- the instrument and what it measures;
- its execution seat and whether separation is epistemically required;
- its likely cost;
- the main thing it may induce or hide.

Light orchestrator-seat probes may run inline. Fresh or parallel subagents run only when the card assigns them or the user approves a non-required control. Durable artifacts, research programs, multiple agents, and Expeditions require an explicit recommendation or direct user request.

## Escalation guide

| Signal                                                  | Candidate move                                                       |
| ------------------------------------------------------- | -------------------------------------------------------------------- |
| The stated request may not be the live inquiry          | Focus interview                                                      |
| Events and explanations are tangled                     | Substrate map                                                        |
| Feelings, priorities, or constraints remain implicit    | Stake map                                                            |
| A repeated word carries the dispute                     | Term scan                                                            |
| Two positions cannot be inhabited together              | Belief-stress rig                                                    |
| The binary may omit an independent axis                 | Third-pole probe / frame projector                                   |
| The frame appears inherited or interested               | Residue collector, using its framing-genealogy lens                  |
| One fact may make the debate moot                       | Ground-condition probe                                               |
| A reversible change can test one uncertain mechanism    | Small experiment                                                     |
| Claims depend on unknown facts                          | Ground-condition probe to name the gap, then a bounded research tool |
| Home vocabulary is exhausted                            | Donor perturbation rig                                               |
| An elegant result may have erased useful parts          | Residue collector / loss audit                                       |
| One public sphere may suppress a live question          | Taboo parallax                                                       |
| A large option space may be dominated by model defaults | Blind possibility-space cartography                                  |
| A reaching result looks expected                        | Frontier rheometer / framing-sensitivity scanner                     |
| Several sound landings remain                           | Candidate spectrograph                                               |
| A costly candidate will guide action                    | Position-preservation and hostile assays                             |

Research is a supporting tool, not an instrument. Use it after a registered probe has named the factual gap, then return the evidence to that instrument's readout with its original claim kind intact.

## Pause guide

Say that no next instrument is warranted when:

- the user can state the tension and the stakes without caricature;
- a cheap observation can settle the empirical remainder;
- probes repeat without adding facts, axes, links, or residue;
- the user has enough material for the actual inquiry even though a larger question stays open.

If a reversible experiment would teach more than another reading, offer it as one of the three caddy choices. Do not treat the suggestion as permission to run it or as an engine transition.

## Artifact boundary

| State                     | Default persistence                                                     |
| ------------------------- | ----------------------------------------------------------------------- |
| Direct answer             | Session record                                                          |
| Walk with any instruments | Session record; no extra organized workspace                            |
| Survey                    | Survey log; source or staging files only when needed                    |
| Expedition                | Promoted Survey/control log, round files, wiki, queue, validation trace |

A Survey does not automatically need a wiki. Start one when reusable research, cross-links, recursion, several agents, or context loss makes graph memory useful.
