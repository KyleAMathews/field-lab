# Belief-Burden Catalog

Use this during Phase 1 of the full dialectic workflow to notice which belief load the Monks must carry. It is a calibration aid, not a diagnosis. Do not name a type to the user.

The parenthetical labels are loose retrieval keys into familiar cognitive patterns, not psychometric claims.

## Convergent visionary (`Ni–Te`)

- **Burden:** Premature convergence on one future.
- **Signal:** A strong thesis; the alternative is weakly described; “I know X, but…”
- **Calibration:** One Monk preserves the thesis's real insight. Another inhabits a genuinely different future, not merely a critique.

## Empathic integrator (`Ni–Fe`)

- **Burden:** Every need feels equally binding; ranking feels like betrayal.
- **Signal:** Many competing needs, frequent “should,” guilt about cutting or choosing.
- **Calibration:** One Monk carries the vision. Another carries actual resources, timing, and people's present capacities.

## Exploratory debater (`Ne–Ti`)

- **Burden:** Commitment itself feels costly; every side can be reframed.
- **Signal:** Fluent arguments on all sides, recurring exploration without decision.
- **Calibration:** Contrast the values revealed by behavioral history with stated values, or assign other poles that force concrete commitments.

## Practical executor (`Te–Si`)

- **Burden:** A proven optimization hides the possibility that the target changed.
- **Signal:** Metrics, precedent, and “in my experience”; resistance to abstract reframing.
- **Calibration:** One Monk shows why the system works. Another questions the goal or changed environment rather than competence.

## Possibility explorer (`Ne–Fi`)

- **Burden:** Several sincere commitments cannot all be met.
- **Signal:** Many values-laden priorities; resistance to ranking them.
- **Calibration:** Give Monks different commitments from the user's own value system and push each to its consequences.

## Steady guardian (`Si–Fe`)

- **Burden:** Embedded practice has become an invisible premise.
- **Signal:** Established process, institutional memory, concern that change will break what works.
- **Calibration:** One Monk recovers the wisdom in the current practice. Another brings concrete cases that meet the same need through a different structure.

## Calibration questions

1. Which belief load is hardest for the user to set down?
2. What insight must one Monk preserve so the user need not defend it?
3. What position can the user not inhabit at full strength?
4. Would these roles reveal structure, or merely flatter a personality story?

Use the answers to shape Phase 2 framing corrections. If the catalog does not fit, ignore it and derive roles from the inquiry itself.
